Agent Catalog

Specialist agent reference for advanced use inside the standard workflow.

Start with $deep-interview, then $ralplan, then execute with $ultragoal. Add $team only when the work genuinely warrants parallel execution. Use the catalog below when you already know you need a specialist lane.

The packaged catalog (omx list --json) is the authority for which roles are installable. Merged and deprecated roles are listed at the bottom for migration context only.
