oh-my-codex

Multi-agent orchestration for OpenAI Codex CLI.

Official project: Yeachan-Heo/oh-my-codex. Official package: oh-my-codex. Third-party projects or forks using names such as “OMX v2” are not official continuations or release lines unless these docs explicitly say so.

npm install -g oh-my-codex

Real global version bumps now print an explicit reminder instead of auto-launching omx setup. When you're ready, run omx setup manually or use omx update to check npm and then run the same setup refresh path. Launch-time update checks are throttled and prompt by default; set OMX_AUTO_UPDATE=0 to disable them or OMX_AUTO_UPDATE=defer to schedule deferred updates without prompting. Fresh setup leaves model_context_window and model_auto_compact_token_limit unset so Codex uses the active model defaults. Rerunning setup removes only unchanged legacy values proven to have been seeded by OMX and preserves explicit, unmarked, and edited values.

What's New in 0.21.3

Released 2026-09-03.

Team wake de-duplication

Duplicate Team wakes are prevented and terminal projections are retired instead of lingering, so completed workers no longer re-trigger coordination work.

Long-session transcript readability

Detached leader tmux scrollback now clamps at 5000 lines (up from 500), so long assistant responses are not discarded from scrollback.

Composer prompt-drift triage

Troubleshooting docs now cover prompt input drift symptoms, measured repro cases, and tmux resize recovery.

Dependency updates

Updated @types/node to 26.4.0, zod to 4.5.2, and @biomejs/biome to 2.5.11.

Quick Start

  1. npm install -g oh-my-codex
  2. After install or real version bumps, run omx setup yourself when you're ready, or use omx update when you also want npm to update OMX first.
  3. omx doctor
  4. omx --xhigh --madmax (trusted environments) or omx

Architecture

User
  -> Codex CLI
     -> AGENTS.md (orchestration brain)
     -> ~/.codex/prompts/*.md (installable active/internal agent prompt catalog)
     -> ~/.codex/skills/*/SKILL.md (skill catalog)
     -> ~/.codex/config.toml (features, notify, MCP)
     -> .omx/ (runtime state, memory, plans, logs)
